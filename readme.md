An investigation of the impact of Gaussian process modelling choices on neutron star equation of state inference from ab-initio theory and gravitational wave observations.

Python environment can be created using `gpr/environmant.yaml`.


EoS samples can be generated by filling out the settings in `gpr/samples.toml` and running `gpr/generate.py`.

The resulting samples are saved as a numpy array in an npy file. The shape of this array is (n,m,o), where 
* n is either 2 (if `convert_eos` is false in `samples.toml`. in order: number density, phi) or 3 (if `convert_eos` is true. in order: energy density, pressure, $c_s^2$),
* m is the number of samples, and
* o is the number of points in each sample (this is whatever number was specified in `n_points` in `samples.toml` + 75 points for the crust eos).
